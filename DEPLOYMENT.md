# Deployment

Create a public GitHub repository named `disease-burden-geographic-risk`, initialise it with a README, then add these project files at repository root.

On Streamlit Community Cloud select this repository, branch `main`, entrypoint `streamlit_app.py`, Python 3.12. Set the application URL to `disease-burden-geographic-risk` if available. No secrets or API keys are needed.

After verifying the live application, copy `portfolio-case-study.html` to the portfolio repository as `pages/disease-burden.html`. Copy `outputs/model-comparison.svg` to `assets/images/burden-model-comparison.svg`, and `outputs/geographic-rate-uncertainty.svg` to `assets/images/burden-geographic-rate-uncertainty.svg`. Update project 10 links only after the deployment is verified. If the deployed URL differs, update both the case study and portfolio card to the actual URL.
